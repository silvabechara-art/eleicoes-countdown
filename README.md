# Eleições Countdown Android — Projeto Completo

Projeto Android nativo para contagem regressiva até 04/10/2026 às 08:00.

## Recursos
- Contagem regressiva em dias e HH:MM:SS
- Relógio local
- Alarme diário às 08:00
- AlarmManager com setAlarmClock
- Reagendamento após reinicialização, mudança de hora e fuso
- Notificação de alta prioridade e vibração
- Tela visual patriótica

## Gerar APK no GitHub
1. Crie um repositório.
2. Envie TODOS os arquivos deste projeto, incluindo a pasta `.github`.
3. Abra Actions.
4. Execute `Build APK`.
5. Baixe o artefato `EleicoesCountdown-debug-apk`.

## Observação
Em Android 12+, o usuário precisa permitir alarmes exatos. Em Android 13+, também precisa permitir notificações.
